# Building SaiLang 0.9.9 for macOS on GitHub

1. Create a repository on github.com and upload the contents of this folder (keep `.github`).
2. Open the **Actions** tab, choose **build-macos**, then **Run workflow**.
3. When it finishes, download the artifact **SaiLang-0.9.9-macos**. It contains the `.dmg` and its checksum.

Apple Silicon Macs only (M1 and later). The app is not signed, so the first time, right-click it and choose Open.
